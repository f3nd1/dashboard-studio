How this scales, in order of what triggers it

  1. Search above 8 dashboards. Below that it is clutter; above it, typing three letters beats reading a list.
  2. Fixed height, scroll inside. The panel never runs off the bottom of the screen, however many exist.
  3. Recent, then all. In practice people return to two or three dashboards. Last-modified order is already stored, so this costs nothing to build.
  4. Count and a way out. "24 dashboards" sets expectations; "View all" hands off to the normal record list for bulk work, which the picker should not try to replace.
  5. Alphabetical within groups. Predictable beats clever once a list is long enough to scan.

Two letters typed. Groups collapse away while filtering — they only help when browsing, and they get in the way when narrowing. The count updates so it is clear the list is filtered rather than short. An empty result offers the action that fixes it.
