# Reference Materials

Everything under this folder is reference material for migration and compatibility work.

- `legacy/`: current dashboard and Server Script source.
- `pilots/`: generated Admission Intelligence and Employee Satisfaction pilot packages.
- `metabase/`: SQL samples and source-query references.
- `archive/`: earlier project documentation retained for context.

Do not treat these files as the new app architecture. Do not reformat or modify them unless a migration task explicitly requires it.
